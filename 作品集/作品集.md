# 商家小程序 Demo 作品集

> 用途：闲鱼 / 小红书接单展示，也可直接二次销售给本地商家
> 技术栈：Vite + React + Tailwind，纯前端，无后端无登录，手机浏览器直接打开
> 全部中文文案、配色、服务项目都集中在 `src/config/` 一个文件里，改文案换行业不用动代码

## 二、逐页详情

### 01 美容院预约系统 Demo

- **【项目名】** 美容院预约系统 Demo
- **【适用行业】** 美容、美甲、理发、SPA、养生馆
- **【核心功能】**
  - 服务卡片展示（名称、时长、价格、卖点）
  - 点服务 → 弹出预约表单：选日期（未来 7 天）+ 选时间段

  - 提交后"预约成功"提示，下方"我的预约"列出全部记录
  - 已占用时段自动置灰，今天已过去的时段自动失效
  - 手机号中间四位打码显示，支持取消预约并释放时段
  - 数据存 localStorage，关掉浏览器再打开记录还在

## 三、怎么拿到预览链接（10 分钟）

每个项目都是独立的静态站点，`npm run build` 后产出 `dist/` 目录，拖到免费托管就有链接：

**方式一：Netlify Drop（最快，不用注册也能传）**
1. 打开 `https://app.netlify.com/drop`
2. 把项目里的 `dist` 文件夹整个拖进去
3. 几秒后得到一个 `https://xxx.netlify.app` 链接

**方式二：Vercel**
1. 打开 `https://vercel.com/new`，选 "Import Project"
2. 把项目文件夹拖进去（或用 GitHub 导入）
3. Framework 选 Vite，Build Command 填 `npm run build`，Output Directory 填 `dist`
4. Deploy 完得到 `https://xxx.vercel.app`

**本地先自己看一眼**
```bash
cd "项目目录"
npm install
npm run dev      # 开发预览，改代码实时刷新
npm run build    # 打包出 dist/，用于部署
```

三个项目各部署一次，你就有 3 个（落地页可拆成 5 个）独立预览链接。

## 四、怎么改成别的行业（你不用懂代码）

每个项目只有一个文件需要改：

| 项目 | 改这个文件 | 能改什么 |
|---|---|---|
| 预约系统 | `src/config/industries.js` | 店名、标语、营业时间、服务项目 / 时长 / 价格、整套配色 |
| 落地页 | `src/config/industries.js` | 公司名、价值主张、服务、案例、评价、联系方式、整套配色 |
| 报价计算器 | `src/config/pricing.js` | 所有单价、户型系数、附加项价格、公司信息 |

配色是"一个色值改全站"——改一个 `brand` 色值，按钮、卡片、高亮全部跟着变，不用逐处调。
